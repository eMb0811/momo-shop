Vision Globale

De la Boutique E-Commerce au Système Observé

momoShop est une boutique moderne pour t-shirts en pur coton peigné mercerisé au Sénégal (21 nuances, coupe ajustée, col structuré) alliant expérience client fluide sur WhatsApp, conteneurisation Docker et monitoring en temps réel sans cookie.

⚡
Expérience Client Storefront
Next.js 15 App Router + React 19 + Tailwind v4
Fiches produit réactives, sélection interactive des tailles (XS à XXL), panier persistent synchronisé et bouton de commande 1-clic direct sur WhatsApp.
🐳
Infrastructure Robuste
Docker Multi-Stage + Caddy 2 SSL
Image Node.js Alpine légère (~130 Mo), certificats HTTPS automatiques Let's Encrypt et déploiement continu par GitHub Actions sur VPS.
📊
Moteur d'Observabilité
momoPulse Engine (/monitoring)
Entonnoir de conversion temps réel respectueux de la vie privée (sans cookie traceur), surveillance de la RAM/CPU et gestion des stocks sans SSH.
Dictionnaire & Stack Technique

Définitions & Rôles des Technologies

Chaque outil a été sélectionné pour maximiser la vitesse, minimiser les coûts d'hébergement et garantir une autonomie technique totale.

▲
Next.js 15 & React 19
Framework React Full-Stack & SSR
Gère à la fois le rendu des pages e-commerce et les routes API (/api/health, /api/monitoring/*) dans un processus serveur unique sans backend séparé.
🔒
Caddy Reverse Proxy
Serveur Web & Gestionnaire SSL Automatique
Remplace Nginx avec zéro configuration de certificat : Caddy obtient et renouvelle les clés SSL Let's Encrypt tout en compressant les flux en Gzip/Zstandard.
🐙
GitHub Actions CI/CD
Intégration & Déploiement Continus
Vérifie le typage TypeScript (tsc), compile le projet en environnement isolé et se connecte en SSH au VPS pour reconstruire les conteneurs Docker sans coupure.
🎨
Tailwind CSS v4
Moteur de style atomique ultra-performant
Compilé nativement pour une vitesse de compilation maximale et une taille CSS minimale, avec injection directe des polices variables hébergées localement.
Architecture & Innovation

L'Entonnoir E-Commerce Sans Cookie

Comment mesurer précisément 100% des visites et conversions sans violer la vie privée ni imposer de bandeau cookie intrusif.

📱
1. Action Visiteur
Arrivée sur la boutique, vue d'une nuance ou clic WhatsApp.
➔
📡
2. Balise Asynchrone
navigator.sendBeacon transmet l'événement en arrière-plan sans ralentir la page.
➔
🛡️
3. Hash Quotidien
SHA-256 (IP + User-Agent + Sel éphémère). Aucun identifiant persistant stocké chez le client.
➔
💾
4. Stockage JSON
Écriture atomique dans src/data/monitoring.json avec rotation automatique sur 90 jours.
DevOps & Résolution de Problèmes

Le Pipeline CI/CD et la Résolution des Pannes

Retour sur les défis techniques réels rencontrés et résolus lors de la mise en production.

⚠️
Le Piège Google Fonts
Sur les serveurs GitHub Actions Ubuntu, next/font/google échouait en build avec un TypeError réseau. Solution : téléchargement et auto-hébergement des polices .woff2 locales.
🔑
Gestion Droits Docker / VPS
Le conteneur Node.js tournant avec l'utilisateur sécurisé `nextjs` (UID 1001), les permissions du dossier `src/data` monté en volume ont été harmonisées dans deploy.yml.
🛰️
Double Sonde de Disponibilité
Une sonde locale intégrée (/api/health) vérifie la RAM, le CPU et l'intégrité des 21 images. Un cron GitHub Actions externe pinge l'URL toutes les 15 minutes.
🔄
Déploiement Zéro Interruption
Grâce aux directives healthcheck de Docker Compose, l'ancien conteneur continue de répondre jusqu'à ce que la nouvelle version soit 100% saine.
Sécurité Avancée

Protection Exclusive de la Console /monitoring

Le tableau de bord momoPulse est conçu pour être accessible uniquement par le gestionnaire de la boutique.

🙈
Invisibilité Publique
Aucun lien visible sur le site. Les balises d'indexation `noindex, nofollow` empêchent les moteurs de recherche d'indexer la route.
🛑
Bouclier Anti-Brute-Force
Le endpoint d'authentification bloque temporairement l'adresse IP pendant 15 minutes dès 5 tentatives infructueuses consécutives.
🔐
Session HttpOnly Sécurisée
Jeton cryptographique HMAC-SHA256 stocké dans un cookie avec attributs SameSite=Strict et Secure, inaccessible depuis le JavaScript navigateur.
✏️
Gestion Stocks & Prix Live
Possibilité de modifier directement les stocks par taille et les prix FCFA dans l'interface sans jamais avoir besoin d'ouvrir une session SSH sur le serveur.
Vision & Évolutions

Points d'Amélioration & Prochaines Étapes

Les chantiers recommandés pour continuer à développer momoShop vers une solution e-commerce d'envergure.

💳
1. Paiement Mobile Money Direct
Wave & Orange Money Checkout
Intégrer les APIs officielles Wave et Orange Money pour permettre au client de payer instantanément en ligne avant confirmation WhatsApp.
🗄️
2. Base de Données Dédiée
PostgreSQL / Supabase
Migrer le fichier products.json et les logs de commandes vers une base SQL managée quand le volume quotidien dépassera les centaines de commandes.
🔔
3. Canal d'Alerte Push Actif
Webhook Discord / Bot Telegram
Renseigner `ALERT_WEBHOOK_URL` dans le fichier .env sur le serveur pour recevoir une notification push immédiate sur mobile dès qu'un client clique sur WhatsApp.
📦
4. Suivi de Livraison Client
Espace Suivi de Colis par Code SMS/WA
Fournir un code de commande unique (ex: MOMO-842) permettant aux clients dakarois de suivre en direct l'expédition de leur paquet de t-shirts.
