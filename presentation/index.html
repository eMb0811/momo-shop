Frontend & Backend Hybride

Next.js 15 & React 19 : Gère simultanément l'affichage ultra-rapide des fiches produit et les endpoints d'observabilité (/api/health, /api/monitoring/track) sous un seul processus.

Tailwind CSS v4 : Styles atomiques optimisés avec polices variables locales (Syne, Plus Jakarta Sans, Space Grotesk).

Infrastructure & Déploiement

Caddy Reverse Proxy : Remplace Nginx. Gère HTTP/3, compresse en Zstandard/Gzip et renouvelle le certificat SSL sans aucune intervention.

GitHub Actions CI/CD : Pipeline automatisé avec build isolé et déploiement SSH sans coupure sur le serveur VPS.

Présenter les technologies : Next.js 15 unifie le front et le back. Caddy apporte le HTTPS automatique. Docker permet une portabilité totale sur VPS.

Innovation · Privacy-First

Monitoring & Analytics Sans Cookie

Le Fonctionnement Technique (momoPulse)

1. Balise Asynchrone · navigator.sendBeacon envoie les événements sans ralentir la navigation.
2. Hash SHA-256 Quotidien · IP + UserAgent + Sel du jour = Identifiant anonyme sur 24h. Zéro cookie écrit chez le visiteur.
3. Stockage Atomique · Données écrites dans src/data/monitoring.json avec rotation auto sur 90 jours.

DevOps · Expérience Réelle

Résolution des Incidents CI/CD & Docker

Incident CI/CD : next/font/google

Sur les serveurs GitHub Actions Ubuntu, le téléchargement des polices Google échouait avec une erreur TypeError: null (reading '1').

Solution : Polices variables WOFF2 auto-hébergées dans src/app/fonts/ avec next/font/local. Build 100% autonome et hors-ligne.

Permissions Volumes Docker VPS

Le conteneur Node.js tournant sous l'utilisateur non-root nextjs (UID 1001), les fichiers créés par Docker sur le volume src/data pouvaient lever des restrictions chmod.

Solution : Normalisation des permissions dans deploy.yml (tolérance non-bloquante) assurant la persistance de monitoring.json.

Montrer la rigueur technique : les problèmes d'intégration continue ont été identifiés, corrigés et documentés.
